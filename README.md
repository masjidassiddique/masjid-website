# Masjid-as-Siddique (RA) Complex website

Responsive, bilingual (English/Bangla) static website. Open `index.html` in a browser to preview. Upload all three website files together to Netlify, GitHub Pages, or any static hosting provider to publish.

## Prayer timetable
The homepage embeds the supplied My-Masjid timetable using an iframe. Whether the timetable appears inside the website depends on My-Masjid's iframe/security policies. A direct timetable link is provided as a fallback. Verify the iframe on the live domain before launch.

## Notes
- The Facebook page could not be accessed for additional factual details, so the site uses information supplied by the requester.
- The mosque graphic is an original CSS illustration, not a photograph of the actual masjid.
- Bank details are displayed as supplied; verify them independently before publishing.
- No online payment processor or backend is included.
